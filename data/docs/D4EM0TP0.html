D4EM0TP0Opérations après-vente : Alarme antieffraction
AVEC ALARME ANTIVOL DEPUIS OPR 8688 JUSQU’A OPR 9001
1. Lecture des défauts
Il est possible de lire les défauts du calculateur d’alarme à l’aide de l’outil de diagnostic :
  • Sirène défaillante
  • Calculateur d’alarme défaillant
  • Calculateur d’alarme non programmé
  • Capteurs volumétriques à ultrasons défaillants
2. Lecture des paramètres
Il n’est pas possible de lire des paramètres à l’aide de l’outil de diagnostic.
3. Test actionneur
Il est possible d’effectuer les tests suivants à l’aide de l’outil de diagnostic :
  • Activation sirène
  • Mise en veille de l’alarme
4. Télécodage
Il est possible de télécoder les paramètres suivants à l’aide de l’outil de diagnostic :
  • Pays : Suisse ou autres
  • Type de sirène : PSA 3 ou PSA 4
  • Antisoulèvement : Absent ou présent
  • Habillage intérieur : Cuir ou tissus
  • Pilotage du voyant : Pas de voyant ; Par le calculateur alarme ; Par le BSI
  • Type de véhicule : Véhicule moyen coupé, véhicule moyen berline ou véhicule moyen break
5. Postéquipement
Il n’est pas possible d’installer une alarme série sur le véhicule, les BSI ne sont pas compatibles.
Il est possible d’installer une alarme accessoirie.

DEPUIS OPR 8688 JUSQU’A OPR 9001
1. Lecture des défauts
Il est possible de lire les défauts suivants à l’aide de l’outil de diagnostic :
  • Défaut éclairage clignotant droit
  • Défaut éclairage clignotant gauche
  • Défaut feux de détresse
  • Défaut sortie témoin feux de détresse
2. Test actionneur
Il est possible d’effectuer les tests suivants à l’aide de l’outil de diagnostic :
  • Commande antibrouillards arrière
  • Commande clignotants droit
  • Commande clignotants gauche
  • Commande feux de position ARD
  • Commande feux de position ARG
  • Commande feux de position AVD
  • Commande feux de position AVG

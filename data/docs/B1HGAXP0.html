2. Dépose
IMPERATIF : Respecter les consignes de sécurité et de propreté spécifiques aux motorisations haute pression diesel injection (HDI) .
Débrancher la borne négative de la batterie.
Déposer :
  • Le filtre à air  (complet)
  • Le tube EGR
  • Le filtre à carburant
Figure : b1hp1sad
Déposer le système d’alimentation d’air intégré.
Obturer :
  • Les conduits d’air  À l’aide de l’outil [7]
  • Le carter chapeaux de paliers d’arbre à cames ; À l’aide de l’outil [8]
Déconnecter et écarter le faisceau électrique des injecteurs diesel.
Désaccoupler :
  • Le tube d’arrivée carburant sur la pompe haute pression carburant
  • Les tubes de retour carburant sur la pompe haute pression carburant , La rampe d’injection commune haute pression carburant
IMPERATIF : Nettoyer les raccords haute pression carburant avant desserrage  (voir opération correspondante).
Desserrer les raccords (/) ( en "a" ) ; À l’aide des outils [3] et [9]  (exercer un contre-couple en " b").
Desserrer les raccords (/) ( en "d" ) ; À l’aide de l’outil [5].
Déposer les tubes haute pression ( 1).
Obturer les orifices sur la rampe commune et sur les injecteurs diesel ; À l’aide de l’outil [4].
ATTENTION : Ne pas intervenir sur l’écrou ( en "c" ).
ATTENTION : Repérer l’emplacement de chaque injecteur diesel par rapport aux cylindres.
Figure : b1hp1sbc
Déposer :
  • Les vis (2)
  • Les brides (3)
  • Les injecteurs diesel (6)
  • Les bagues d’étanchéité (5)
  • Les joints (7)
  • Les grains d’appui ( 4)
Obturer les puits d’injecteurs diesel ; À l’aide de l’outil [4].
3. Repose
ATTENTION : Respecter les couples de serrage .
ATTENTION : Remplacer les joints d’étanchéité ( 7) par des joints neufs.
3.1. Injecteurs diesel réutilisés
ATTENTION : Reposer les injecteurs diesel dans les cylindres en respectant leurs emplacements par rapport aux cylindres notés lors du démontage.
3.2. Injecteurs diesel neufs
ATTENTION : Relever le numéro de classification des injecteurs diesel . Noter le ou les cylindres recevant un injecteur diesel neuf.
3.3. Opérations communes
ATTENTION : Remplacer le ou les tubes haute pression d’injection diesel déposés.
Reposer :
  • Les grains d’appui ( 4)
  • Les joints (7)  (neuf)
  • Les bagues d’étanchéité (5)
  • Les injecteurs diesel (6)
  • Les brides (3)
  • Les vis (2)
  • Les tubes haute pression carburant (1)  (neuf)
ATTENTION : Visser à la main, les raccords en " a" et "d" des tubes (1) haute pression d’alimentation des injecteurs diesel à fond de filet, côté injecteurs diesel et côté rampe d’injection commune haute pression.
Serrer les raccords ( 1) sur les injecteurs diesel ; À l’aide des outils [1], [2], [3].
ATTENTION : Appliquer un contre-couple ( en "b" ).
Serrer les raccords (1) sur la rampe d’injection commune haute pression carburant ; À l’aide des outils [1] et [5].
NOTA : Reposer le tube haute pression, entre la pompe haute pression carburant et la rampe d’injection commune haute pression.
Continuer les opérations de repose dans l’ordre inverse des opérations de dépose.
Actionner pendant 120 secondes la pompe d’amorçage manuelle pour amorcer le circuit de carburant.
Rebrancher la batterie.
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
4. Contrôle d’étanchéité
IMPERATIF : Pulvériser le produit [ 6] sur les raccords ( en "a", "d" ).
Laisser sécher le produit.
Démarrer le moteur.
Vérifier l’absence de fuite.
Accélérer jusqu’à un régime de 4000 tr/mn.
Vérifier l’absence de fuite.
Faire un essai routier :
  • Engager le 3ème rapport
  • Stabiliser le régime moteur à 1000 tr/mn
  • Accélérer le moteur à 3500 tr/mn
Vérifier l’absence de fuite.
Remplacer les pièces défectueuses  (si nécessaire).

C5GG0SP0Dépose - repose : Garniture de pavillon
TOIT OUVRANT CDE ELECTRIQUE
1. Dépose
Figure : c5gp04bd
Dégrafer partiellement le joint d’encadrement (5).
Découper les cordons de colle ( 6).
Déposer :
  • Le plafonnier (7)
  • Les garnitures supérieures de custode (1) ; (14)
  • Les garnitures supérieures de pied de milieu (2) ; (13)
  • Les garnitures de montant de baie (3) ; (12)
  • Les poignées de maintien (4) ; (11)
  • Les pare-soleil et supports (10)
  • La console centrale de pavillon (9)
  • Le jonc d’entourage (8)
  • La garniture de pavillon (15)
2. Préparation
Figure : c5gp04cd
Appliquer 2 cordons de colle (6) (adhésif joint polyuréthane A3).
Vérifier que les bandes autoagrippantes ( 16) sont correctement collées.
3. Repose
Poser la garniture (faire coïncider les différentes ouvertures).
Continuer les opérations de repose dans l’ordre inverse des opérations de dépose.
Nettoyer la garniture à l’aide de chlorotène.

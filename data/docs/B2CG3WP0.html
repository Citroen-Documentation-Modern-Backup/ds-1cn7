B2CG3WP0Dépose - repose : Calculateur boîte de vitesses automatique autoactive (type AL4)
1. Dépose
Figure : b1bp204c
Débrancher :
  • La batterie (2)
  • Le connecteur du calculateur moteur (1)
Déposer :
  • La batterie (2)
  • Le bac à batterie (3)
Figure : b1bp205c
Déposer :
  • Le connecteur (4)
  • Les 3 vis (6)
  • Les vis de fixation du calculateur (5) sur le support (7)
  • Le calculateur (5)
L’échange du calculateur boîte de vitesses nécessite d’effectuer les opérations suivantes :
  • La lecture de la valeur du compteur d’usure d’huile et la recopie de celle-ci dans le nouveau calculateur boîte de vitesses
  • Le télécodage du nouveau calculateur boîte de vitesses
  • Un apprentissage pédale d’accélérateur
NOTA : Pour ces opérations, suivre la procédure de l’outil de diagnostic.
Faire un test routier.
2. Repose
Procéder dans l’ordre inverse des opérations de dépose.
IMPERATIF : S’assurer de la présence du protecteur plastique ( 8) sur le support calculateur boîte de vitesses.

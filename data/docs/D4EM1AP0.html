D4EM1AP0Opérations après-vente : Antidémarrage
BOITIER DE SERVITUDE (BSI) COMM 2000 DEPUIS OPR 9002
Les éléments participants à l’antidémarrage du véhicule doivent être appariés entre eux pour que le moteur fonctionne.
Les procédures d’appariement des éléments ci-dessous sont réalisées à l’aide de l’outil de diagnostic et du code d’accès client :
  • BSI
  • clés
  • Calculateur moteur (sauf DW8B)
  • Électrovanne pompe diesel (DW8B)
1. Remplacement du BSI
Lors du remplacement du BSI, il faut effectuer les opérations suivantes :
  • Programmer en mémoire le code d’accès client
  • Réapprendre toutes les clés
  • Réaliser l’appariement avec le calculateur moteur
ATTENTION : L’opérateur a 3 tentatives pour programmer le code d’accès client dans la mémoire du BSI, ensuite, le processus est neutralisé pendant 15 minutes.
NOTA : Le code d’accès client ne peut pas être lu dans la mémoire du BSI.
2. Apprentissage des clés
L’identifiant du transpondeur de la clé doit être mémorisé dans le BSI pour permettre le démarrage du véhicule . Le BSI peut mémoriser 5 identifiants au maximum avec ou sans télécommande.
Pour mémoriser l’identifiant de la clé dans le BSI, il est indispensable de réapprendre tous les identifiants des clés du véhicule.
L’identifiant du transpondeur d’une clé perdue ou volée est désactivé de la mémoire du BSI lors du réapprentissage des clés restant en possession du client.
3. Remplacement du calculateur moteur
Le calculateur moteur est livré télécodé par le magasin de pièces de rechange.
Le calculateur moteur est verrouillé par défaut.
Lors du remplacement du calculateur moteur, il faut effectuer les opérations suivantes :
  • Programmer le code d’accès client dans la mémoire du calculateur moteur
  • Apparier le calculateur moteur au BSI
ATTENTION : L’opérateur a 3 tentatives pour programmer le code d’accès client dans la mémoire du calculateur moteur. La troisième tentative de programmation du code d’accès client est définitive. Le code d’accès client ne peut plus être changé.
NOTA : Le remplacement d’un calculateur moteur pour un moteur DW8B ne nécessite aucune opération liée à l’antidémarrage.
4. Remplacement de l’électrovanne pompe diesel (DW8B)
Lors du remplacement de l’électrovanne de la pompe diesel, il est nécessaire d’apparier l’électrovanne de la pompe diesel avec le BSI.
L’électrovanne de la pompe diesel moteur est verrouillé par défaut.
5. Garantie
ATTENTION : Lors du retour en garantie d’un calculateur moteur, d’un BSI ou d’une électrovanne diesel, il est obligatoire d’y adjoindre le code d’accès client.

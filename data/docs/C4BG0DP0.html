C4BG0DP0Dépose - repose : Volet arrière
1. Dépose
Déposer ( côté droit) :
  • La garniture de custode
  • Le support de tablette
Déconnecter le connecteur d’alimentation arrière.
Désaccoupler le tuyau lave-vitre.
Figure : c4bp148c
Opération nécessitant deux opérateurs.
de chaque côté :
  • Déclipper les stabilisateurs (3)
  • Déposer l’axe de charnière (1) (axe vissé)
Tirer le faisceau électrique ( 2) du pavillon.
Déposer le volet arrière (4).
2. Repose
Procéder dans l’ordre inverse des opérations de dépose.

C4BS09P0Déshabillage - Habillage : Volet arrière
1. Déshabillage
Déposer le volet arrière (voir opération correspondante).
Figure : c4bp12hc
Déclipper la poignée ( 2), À l’aide d’un petit tournevis.
Déposer :
  • La poignée (vis (4))
  • Les pions agrafes (1), (3) et (5)
  • La garniture intérieure
Figure : c4bp12jc
de chaque côté :
  • Chasser l’axe central, puis déposer le pion (6)
  • Dégrafer le bandeau latéral (7)
  • Déposer les écrous papillon (8)
  • Dégrafer le bandeau inférieur
Figure : c4bp12kd
Déposer les feuilles d’étanchéité (17).
Débrancher :
  • Le connecteur de 3ème feu de stop
  • Les connecteurs de lunette chauffante ( 9) et (14)
  • Le connecteur de condamnation centralisée (12) (suivant équipement)
  • Le connecteur d’éclaireur de plaque de police (13) (de chaque côté)
  • Le connecteur du moteur d’essuie-vitre (15)
  • Le contacteur à bille (19) (percer le rivet du fil de masse Ø 6 mm)
  • Le tuyau de lave-vitre (16)
Couper les colliers plastique.
Déposer le faisceau électrique par l’orifice ( 10).
Déposer :
  • La serrure (vis (11)) (de chaque côté)
  • Les passe-fils (18)
Figure : c4bp12lc
Déposer :
  • Le bras-balai d’essuie-vitre
  • Le moteur essuie-vitre (percer les rivets (21) à Ø 6,5 mm)
  • Le bandeau (20) (vis (22) écrou (23) de chaque côté)
Figure : c4bp12mc
Déposer :
  • Les éclaireurs de plaque de police ( 24) (clipper)
  • Le support de verrou (languettes (25)) (de chaque côté)
Déposer la lunette arrière (voir opération correspondante).
2. Habillage
Procéder dans l’ordre inverse des opérations de déshabillage.

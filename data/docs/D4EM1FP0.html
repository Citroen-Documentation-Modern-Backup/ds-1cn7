Il est possible de lire les défauts suivants à l’aide de l’outil de diagnostic . La lecture des défauts doit se faire moteur tournant :
  • Défaut calculateur de climatisation
  • Défaut touche tableau
  • Défaut sonde température d’eau
  • Défaut sonde température extérieure
  • Défaut information vitesse véhicule
  • Défaut information pression réfrigérant
  • Défaut information régime moteur
  • Défaut absence de communication entre le BSI et le calculateur de climatisation
  • Défaut information température évaporateur
  • Défaut sonde température évaporateur
  • Défaut sonde température habitacle
  • Défaut sonde air soufflé aération
  • Défaut tension recopie du pulseur
  • Défaut sonde air soufflé pied
  • Défaut tension batterie +VAN CONFORT
  • Défaut consigne température
  • Défaut consigne pulseur
  • Défaut consigne distribution
  • Défaut moteur recyclage
  • Défaut moteur distribution
  • Défaut moteur recyclage
  • Défaut moteur mixage
  • Défaut commande pulseur
  • Défaut sonde habitacle (rotor bloqué)
2. Test actionneur (version RTFD)
Il est possible d’effectuer les tests suivants à l’aide de l’outil de diagnostic . Le test actionneur pulseur s’effectue moteur tournant :
  • Moteur recyclage
  • Moteur mixage gauche
  • pulseur
3. Télécodage (version RF/RTFD)
3.1. Géré par le calculateur de climatisation
Il est possible de télécoder les paramètres suivants à l’aide de l’outil de diagnostic :
  • Type de conduite (direction à droite, direction à gauche)
  • Type de motorisation (ADIN, non ADIN, HDi, non HDi, grand froid, non grand froid)
3.2. Géré par le calculateur BSI
Il est possible de télécoder les paramètres suivants à l’aide de l’outil de diagnostic :
  • Présence climatisation RFTD (NON/OUI)
  • Option Tout ou Rien pour capteur de pression de réfrigération (absente/présente)
  • Présence climatisation (NON/OUI)
  • Option climatisation VAN (absente/présente)
  • Type de climatisation (RF/RFTD)
  • Option climatisation sans diagnostic (absente/présente)
4. Lecture des paramètres (version RTFD)
Il est possible de lire les paramètres suivants à l’aide de l’outil de diagnostic :
  • Tension batterie (+ VAN)
  • Température habitacle
  • Température air soufflé aération
  • Tension recopie pulseur
  • Température air soufflé pied
  • Consigne température
  • État du pulseur
  • État de la distribution
  • Tension pulseur
  • État du recyclage d’air
  • Position du volet de mixage

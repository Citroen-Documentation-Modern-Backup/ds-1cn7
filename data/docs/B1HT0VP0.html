B1HT0VP0Évolution : Porte-injecteurs diesel
Véhicule concerné : XSARA 2 2.0 HDi.
Application : À partir du N° OPR 8939.
Évolution :
  • Les moteurs DW10ATED/L4 BVM sont équipés de nouveaux types de porte-injecteurs diesel repérés en fonction de leur diamètre de conduit d’injection (nouvelle caractérisation)
  • Nouveau calculateur d’injection avec nouvelles cartographies intégrant la classe d’injecteur équipant le moteur
NOTA : Les moteurs type DW10ATED/L4 BVA sont équipés d’origine des nouveaux injecteurs diesel (depuis le N° OPR 8911).

3. Réparation
3.1. Échange porte-injecteur diesel
Lors de l’échange d’un porte-injecteur diesel, commander un élément de même classe.
NOTA : Le montage de 4 porte-injecteurs diesel de classe différente est possible, à condition de télécoder leur nouvelle classe dans le calculateur d’injection.
3.2. Échange d’un calculateur d’injection
Commander le nouveau calculateur d’injection (télécodé en P.R).
IMPERATIF : Fournir le code d’accès et le numéro VIN pour que le service des Pièces de Rechange télécode le nouveau calculateur d’injection.
Contrôler les paramètres télécodés.
Télécoder la classe des porte-injecteurs équipant le moteur (si nécessaire).
3.3. Pièces de rechange
Le service "Pièces de Rechange" commercialise les anciennes et les nouvelles pièces.
À épuisement du stock, seules les nouvelles pièces seront disponibles au Service des Pièces de Rechange.
NOTA : Le montage d’un nouveau porte-injecteur diesel de classe Y sur un ancien montage est possible.
Le montage d’un nouveau calculateur sur un ancien montage est possible à condition de télécoder la classe Y.
